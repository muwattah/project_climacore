# ClimaCore

Premium airco-installatie & koeltechniek website for ClimaCore (Vlaanderen).

**Live:** https://muwattah.github.io/project_climacore/

## Structure

- `index.html` – Homepage with Airco Check, price tools, photo CTA, projects, FAQ
- `css/styles.css` – Design system
- `js/main.js` – Wizard, FAQ, price configurator
- `pages/` – Service & local landing pages

## GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: **main** → Folder: **/ (root)** → Save.

Then open the live URL (hard refresh if needed).
