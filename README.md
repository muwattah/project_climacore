**Fictief Belgisch airco- & koeltechniekbedrijf**  
Hoogwaardige, conversiegerichte website ontworpen als ware het een €20.000+ bureau-opdracht.

---

## 1. Websiteconcept

ClimaCore positioneert zich als **technisch expert + betrouwbare partner**, niet als goedkope installateur.  
De site combineert de uitstraling van een premium architectenbureau met de helderheid van een modern technologiebedrijf.

**Kernbelofte:**  
> De juiste airco voor jouw woning. Vakkundig geïnstalleerd. Zonder verrassingen.

**Primaire conversiedoelen (in volgorde van prioriteit):**
1. Airco Check wizard → lead
2. Foto upload → lead
3. Prijsindicatie / adviesaanvraag → lead
4. Telefoon / e-mail

## 4. SEO-strategie

### Architectuur (geen “alles-op-één-pagina”)
Elke belangrijke zoekintentie krijgt een eigen, inhoudelijk sterke pagina.

| Zoekintentie                    | URL                              |
|--------------------------------|----------------------------------|
| airco installatie              | /airco-installatie/              |
| airco prijs / kosten           | /airco-prijs/                    |
| airco verwarming               | /airco-verwarming/               |
| multi split airco              | /multi-split-airco/              |
| airco onderhoud                | /airco-onderhoud/                |
| airco herstelling              | /airco-herstelling/              |
| koeltechniek                   | /koeltechniek/                   |
| airco installateur Antwerpen   | /airco-installateur-antwerpen/   |
| airco installateur Mechelen    | /airco-installateur-mechelen/    |
| …                              | …                                |

### Title tags (voorbeelden)
- Homepage: `ClimaCore | Airco installatie & koeltechniek in Vlaanderen`
- Installatie: `Airco installatie | Vakkundig geplaatst – ClimaCore`
- Prijs: `Airco prijs & kosten | Transparante indicatie – ClimaCore`
- Antwerpen: `Airco installateur Antwerpen | ClimaCore`

### Meta descriptions
Kort, benefit-gericht, met CTA-hint. Max. ±155 tekens.

### Lokale SEO
- Unieke content per stadspagina (geen template-swap)
- Projecten per regio
- Google Business Profile embed / reviews
- LocalBusiness + Service schema
- Duidelijke NAP in footer

### Technische SEO
- Semantic HTML5
- Correcte H1 → H2 → H3 hiërarchie
- Canonical tags
- XML sitemap + robots.txt
- Open Graph
- WebP/AVIF images + alt-teksten
- Core Web Vitals focus (lichte CSS/JS, geen zware frameworks)
- Interne linking tussen diensten, projecten en kenniscentrum

### AI / GEO optimalisatie
- Duidelijke definities en stappenplannen
- Tabellen en vergelijkingen (single vs multi-split)
- FAQ’s met directe antwoorden
- Lokale, concrete informatie

## 7. Design system

**Kleuren**
- Achtergrond: `#f8f9fa` (gebroken wit)
- Surface: `#ffffff`
- Anthraciet: `#1a1d21`
- Accent: `#0d7377` (koel, technisch teal)
- Text muted: `#5a6169`

**Typografie**
- Inter (of system-ui stack)
- Sterke hiërarchie, veel witruimte

**Stijl**
- Minimalistisch, premium, technisch
- Geen goedkope gradients, geen stockfoto-clichés
- Subtiele schaduwen en borders
- Grote, duidelijke knoppen (mobile-first)

---

## 8. Mobiele UX

- Sticky bottom bar: 📞 Bel · 💶 Prijs · 📸 Foto
- CTA’s groot genoeg voor éénhandsbediening
- Wizard volledig bruikbaar op small screens
- 60–70% van traffic verwacht mobiel

## 9. Contentstrategie (Kenniscentrum)

Voorbeelden van artikelen (geschreven voor mensen, niet keyword-stuffing):

- Hoeveel kost een airco inclusief installatie?
- Welke airco heb ik nodig voor 30 m²?
- Kan een airco een huis verwarmen?
- Verbruikt een airco veel elektriciteit?
- Single-split vs multi-split
- Waar plaats je een airco in de slaapkamer?
- Hoe onderhoud je een airco?
- Airco in appartement: waar moet je rekening mee houden?
- Airco installeren in bestaande woning
- Hoe stil is een moderne airco?

Elke pagina: duidelijke H1/H2/H3, interne links, praktische antwoorden.
